# Neox CLI

Terminal agent for NeoX — Ink REPL, slash commands, print and headless modes. Same production engine as Desktop.

## Install

```bash
npm install -g @mk-co/neox-cli
neox
```

Binaries and installers: [neox-dev.com/download](https://neox-dev.com/download) · [Releases](https://github.com/neoxlabs/neox-cli/releases)

## Features

- Full agent sessions in the terminal
- Slash commands: `/model`, `/checkpoint`, `/rollback`, `/mcp`, …
- Print / headless modes for scripts and CI
- Multi-provider · Shadow Git checkpoints · OS sandbox (where enabled)
